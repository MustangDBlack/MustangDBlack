### 🚀 Productos y Soluciones Destacadas

#### 🛒 Sistema de Gestión Comercial y POS (Implementación Comercial Activa)
Software integral B2B actualmente operativo en el sector ferretero para la administración total del negocio y procesamiento de ventas en mostrador.
*   **Stack:** Laravel, React, Inertia.js, Tailwind CSS, Lucide React, MySQL.
*   **Arquitectura SPA:** Navegación fluida sin recargas de página y soporte nativo para Modo Oscuro/Claro.
*   **Punto de Venta Adaptativo:** Soporte para artículos generales y pesables (Kilos, Metros, Unidades), cobros con pagos mixtos (Efectivo, Transferencias, Tarjetas) e impresión directa en ticketeras térmicas.
*   **Gestión Financiera e Inventario:** Control de caja en tiempo real (arqueos, ingresos/egresos), alertas críticas de stock y categorización de proveedores.

#### 📊 Sistemas de Gestión a Medida (PHP Nativo)
Planificación y desarrollo de sistemas core para gestión comercial e inventarios. Enfoque en lógica estructurada, optimización de consultas SQL, seguridad y manejo de sesiones desde los cimientos del lenguaje PHP, garantizando un rendimiento ligero en entornos de hardware limitados.

#### 🏫 Plataforma de Gestión Institucional - IES Nuevo Horizonte
Sistema integral para la administración educativa y la gestión de torneos deportivos regionales, combinando el poder del backend de Laravel con interfaces dinámicas de Filament.

#### 🛵 PARKINH - Reserva Digital de Estacionamientos
Plataforma interactiva para el control y reserva de cupos de estacionamiento de motocicletas en entornos escolares, con gestión de usuarios y disponibilidad en tiempo real.

#### 🚌 Modernización Tecnológica en Transporte Público (SAETA)
Propuesta de arquitectura de software orientada a la modernización, escalabilidad y monitoreo continuo de flotas, desarrollada bajo estándares de alta concurrencia.
